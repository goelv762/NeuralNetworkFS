# Neural Network From Scratch
This project features fully connected neural network training and testing using the MNIST data set.

## Description
No external libraries are used for this project so everything from the linear algebra to the data loading is purpose built.

## Models
The models included in the [models folder](models/) use layers of size 784, 128, 64 and 10 (output layer). As seen by the file naming format, the highest accuracy included is 97.2%.

## Compilation
Only tested on linux. Create a build folder and compile using CMake.
